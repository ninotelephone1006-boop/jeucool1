# Textures d’interface Minecraft

Les images de ce dossier proviennent des ressources de **Minecraft Java Edition 1.21.4** (textures de conteneur, boutons, onglets et barre rapide). Elles sont conservées telles quelles et servent à reproduire l’interface dans le jeu.

Source du miroir public des ressources : `InventivetalentDev/minecraft-assets`, branche `1.21.4` (`assets/minecraft/textures/gui/`). Les textures Minecraft restent la propriété de Mojang Studios / Microsoft.
